# Evidence Tracer

For each material impact claim:

1. Start with the causal enterprise entity, such as supplier or site.
2. Follow only typed relationships supported by the ontology or stable operational keys.
3. End at the impacted commitment, governed contract, and accountable organization.
4. Record each canonical ID, label, entity type, and outgoing relationship.
5. Cite the source systems that establish the path.
6. Assign confidence based on the lowest-confidence material mapping in the path.

Evidence paths must be concise enough for a decision maker to inspect but complete enough for a data steward to reproduce.
