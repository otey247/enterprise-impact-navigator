# Project instructions

## UI copy

Read `DESIGN.md` before writing or changing any text a user sees (headings, cards, labels, toasts, empty states).

Short version: use plain product language. Headings are 1 to 5 words. Supporting text is one short sentence or nothing. Never use the interface to explain architecture, AI reasoning, or the semantic model. Name the user's task, not the system's internal process.

## Commands

- `npm start` serves the app on port 3000 (no install step)
- `npm run validate` checks the demo data and runs the tests
